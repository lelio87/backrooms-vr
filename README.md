# THE BACKROOMS VR — La Sombra

Juego web de exploración y horror hecho con A-Frame 1.5.

**Jugar:** https://lelio87.github.io/backrooms-vr/

## Controles
- **Móvil:** joystick izquierdo para moverte, deslizá la derecha para mirar.
- **PC:** WASD o flechas, arrastrá el mouse para mirar.
- **VR:** stick izquierdo para caminar, stick derecho para girar.

Encontrá la llave roja, activá el portal y escapá de la sombra. La linterna la frena.
